
If you have content available on the web that you would like to import into iCatcher! you can do so by using the shortcuts app to create a shortcut to grab the media. Below are the steps to create a shortcut to import media from a web page.


1. Open shortcuts app
2. Create a new shortcut
3. Add the action "Import Episode from Web"
4. Configure the shortcut by tapping the info i icon and enabling Show in Share Sheet and disabling Show in Search.
5. Next configure the receive options that starts with "Apps and ..." in there you can clear all options except for the ones the section labeled Web
6. Configure the Webpage URL so that it gets its value from the shortcut input.
Published Date, either set it to Current Date (one of the options) or select ask each time

Now when you visit a web page that has a media player you can try activating the share action and find your new shortcut in the list of available share options.
