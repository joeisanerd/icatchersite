
Custom Playlists have the option to enabled **Continuous Playback**. You can enable **Continuous Playback** from the now playing screen by tapping the button below the time elapsed. 

You can also enable continuous playback within one of the builtin playlist the same way.

Playing episode from within a podcast will give you the same option to toggle continuous playback. There is a podcast default in the settings tab for Continous Playback. This allows you to set the default behavior when starting playback from a podcast. That same setting is now visible in each podcasts settings.

<!-- **Note:** Disabling **continuous playback** will also prevent [Continuous Playlists](/help/backtobackplaylists) from working if you have that setting enabled. -->
