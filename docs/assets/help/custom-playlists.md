      
There are three ways to create a playlist in iCatcher.
1) From the playlists tab you can tap the **New +** icon to create a new playlist. 
- Auto-Fill playlist is a fills the playlist based on the rules
- Empty playlist requires that you add episodes explicitly

2) You can also create a playlist by dragging and dropping episodes or podcasts onto the New+ icon. This will create an Auto-Fill playlist that includes the episodes/podcasts you dropped on it.

3) Tap and hold on an episode or multi-select episodes and access the action menu you can create or add to a playlist.

Once you have a playlist created you can edit that playlist by tapping the i icon. This will allow you to change the playlist settings and rules.
1. Set a name for your playlist
2. Specify the types of media (tap to change)
3. Optionally you can select an image to use for your playlist
4. Indicate if you want this playlist to have continuous playback
5. Specify how you want to include episodes by Podcast, Episode, Keywords
6. You can exclude certain podcasts or episodes from the playlist as well.
7. Specify individual downloaded or streaming episodes for the playlist.

If you just want a playlist that includes all podcasts, then do not select any podcasts or exclude any podcasts or specify any keywords and it will use all of the podcasts available to make the playlist.
